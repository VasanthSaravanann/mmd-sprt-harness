## Task 1: Gate 0 $\text{MMD}^2$ Tail-Sensitivity Parameter Sweep

- **Target File:** `benches/eval_gate0_sensitivity.py`
- **Output Artifact:** `paper/figures/fig1_gate0_sensitivity.pdf`
- **Execution Specs:**
  1. Generate 1,000 synthetic trajectory action streams ($N = 1000$ tokens per trajectory).
  2. Sweep tail exfiltration token injection rates from $0.0\%$ to $5.0\%$ in steps of $0.1\%$.
  3. Compute length-normalized character 3-gram Gaussian-RBF $\text{MMD}^2$ (with absolute floor threshold $\epsilon_{\text{prod}} = 0.015$) against standard mean-embedding cosine distance for each step.
  4. Render dual-line vector plot comparing metric response across the perturbation gradient.
- **Assertion:** Cosine distance remains flat ($\approx 0.0007$), while 3-gram RBF $\text{MMD}^2$ crosses $\epsilon_{\text{prod}} = 0.015$ at $1.0\%$ injection.

## Task 2: SPRT Efficiency & Noise Sensitivity Benchmark

- **Target File:** `benches/eval_sprt_efficiency.py`
- **Output Artifact:** `paper/figures/fig2_sprt_token_savings.pdf`
- **Execution Specs:**
  1. Simulate 1,000 failing trajectory rollouts across stochastic temperature noise levels $\sigma^2_{\text{temp}} \in [0.1, 1.0]$.
  2. Compare fixed-horizon evaluation ($K=8, k=6$) against prior-anchored SPRT early stopping with $N \ge 5$ rolling window exponential decay fit ($d^{(i)} = \beta_0 e^{-\lambda i}$).
  3. Log cumulative token spend per rollout and compute empirical False Positive Rate ($\text{FPR}$).
  4. Render Cumulative Density Function (CDF) plot of token consumption.
- **Assertion:** SPRT achieves $\ge 35\%$ token savings on failing rollouts while maintaining $\text{FPR} < 5.0\%$.

## Task 3: IPW Variance Stabilization & Weight Winsorization Sweep

- **Target File:** `benches/eval_ipw_variance.py`
- **Output Artifact:** `paper/figures/fig3_ipw_winsorization.pdf`
- **Execution Specs:**
  1. Sample propensity weights from Heavy-Tailed Pareto distributions across shape parameter gradient $\alpha \in [1.1, 3.0]$.
  2. Calculate effective sample size $n_{\text{eff}} = \frac{(\sum w_i)^2}{\sum w_i^2}$ for raw vs. $P_{99}$-winsorized weights ($w_i^{\text{capped}} = \min(w_i, P_{99}(\mathbf{w}))$).
  3. Calculate weighted Spearman rank correlation $r_{2, \text{IPW}}$ against known ground-truth viability rankings.
  4. Render plot of Weight Skewness ($\alpha$) vs. Effective Sample Size ($n_{\text{eff}}$), highlighting the $n_{\text{eff}} \ge 30$ gate threshold.
- **Assertion:** Unwinsorized weights collapse $n_{\text{eff}} < 30$, while $P_{99}$ winsorization preserves statistical power ($n_{\text{eff}} \ge 30$) up to heavy tail skewness $\alpha = 1.2$.

## Task 4: SPRT Rolling Fit Window ($N$) Ablation Study

- **Target File:** `benches/eval_sprt_ablation.py`
- **Output Artifact:** `paper/figures/fig4_sprt_window_ablation.pdf`
- **Execution Specs:**
  1. Execute 2,000 stochastic evaluation trajectories across rolling window sizes $N \in \{3, 4, 5, 6, 7\}$.
  2. Fit exponential decay $d^{(i)} = \beta_0 e^{-\lambda i}$ and compute $R^2$ goodness-of-fit.
  3. Measure False Halt Rate ($\text{FPR}$) and token savings percentage for each $N$.
  4. Render dual-axis plot of Fit Window Size ($N$) vs. Token Savings (%) and False Halt Rate (%).
- **Assertion:** $N=3$ yields high false halts ($\text{FPR} > 12\%$) due to 1 degree of freedom, whereas $N=5$ stabilizes $\text{FPR} < 5.0\%$ while retaining $>35\%$ token savings.

## Task 5: eBPF Microsecond Latency & Race Window Stress Benchmark

- **Target File:** `benches/eval_ebpf_race_window.py`
- **Output Artifact:** `paper/figures/fig5_ebpf_latency.pdf`
- **Execution Specs:**
  1. Measure system call execution delta between exfiltration touch event (`sys_enter_connect`) and mitigation action (`SIGKILL`) under CPU load generated by `stress-ng`.
  2. Benchmark userspace UNIX socket polling (`/tmp/verifier.sock`) against in-kernel eBPF `bpf_send_signal` execution.
  3. Record Exfiltration Prevention Failure Rate as a function of enforcement latency.
  4. Render logarithmic box plot of enforcement latency distribution ($\mu\text{s}$).
- **Assertion:** Userspace socket IPC yields latency of $1.8\text{ms}$ to $4.2\text{ms}$, while eBPF in-kernel termination executes in $<10\mu\text{s}$.
